# ADR 0007 - Memory only through explicit promotion rules
Style rule: a candidate pattern from an approved edit is promoted after it appears in >= 3 distinct proposals within 30
days (or the user clicks "remember"); never if it conflicts with policy. Outcome insight: promoted per category only
with >= 5 outcomes and a >= 10-point reply-rate lift between strategies. Inputs are typed events, never raw tool output.
The Settings screen lists and deletes everything learned.
